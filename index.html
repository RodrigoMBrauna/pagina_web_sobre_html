Principais Tags do HTML

HTML (Linguagem de Marcação de HiperTexto) é o bloco de construção mais básico da web. Define o significado e a estrutura do conteúdo da web. Outras tecnologias além do HTML geralmente são usadas para descrever a aparência/apresentação (CSS) ou a funcionalidade/comportamento (JavaScript) de uma página da web.

Aqui estão algumas das principais tags:

Tags de Cabeçalho

As tags de cabeçalho vão de <h1> até <h6>, sendo <h1> a mais importante.

Texto e Formatação

Podemos estilizar o texto com diversas tags:

  • <i> - Texto em itálico
  • <u> - Texto sublinhado
  • <strong> - Texto em negrito
  • <small> - Texto menor
  • <del> - Texto deletado
  • <mark> - Texto destacado

Listas

Podemos criar listas ordenadas e não ordenadas:

  1. Item 1
  2. Item 2
  • Item A
  • Item B

Links e Separação

Para criar um link que seja carregado na mesma aba do seu site, usamos a tag <a href="#link">HTML.

Para criar um link que seja carregado em uma nova aba do navegador, usamos a mesma tag combnado com target"_blank" <a href="#link">HTML.
